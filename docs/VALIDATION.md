## Что проверяется

- 103 теста домена: строгие деньги, комиссии, способы оплаты, обязательные поля, лишние поля, время с офсетом, нормализация UTC, неизменяемость и равенство. Среди них — многодневная поездка без искусственного лимита 24 часов.
- 10 тестов сводки, времени и интеграции: пример из задания, случайные данные с независимым эталоном, дни DST 23/25 часов, границы Алматы, сортировка и переход через полночь, конфигурация пояса, POST 201/200/409/422, сохранение после повторного открытия SQLite, повтор seed, конкурентные повторы.
- 4 теста React: загрузка сводки/переключение дней, пустое состояние, ошибка сети/повтор, POST с целочисленными суммами и сообщение об безопасном повторе.

## Направленные мутационные проверки

Три изменения временно внесены в исходники; каждый вызвал ожидаемое падение теста:

| Ошибка | Что её обнаружило |
|---|---|
| `net = revenue + commission` | Ожидание net=3315 для примера |
| Не сравнивать данные при одинаковом ID | Ожидание HTTP 409 вместо 200 |
| Включить следующую полночь в предыдущий день | Ожидание исключить поездку нового дня |

После каждой проверки исходники восстановлены. Чтобы исключить устаревший Python bytecode, кеш очищался, запись bytecode отключалась. После восстановления выполнен полный зелёный прогон. Это три целевые проверки, а не полный mutation score всего проекта.
