# Отправка проекта

1. Распакуйте архив. Корнем репозитория должна быть папка с README.md, docker-compose.yml, server и client.
2. Создайте публичный репозиторий GitHub/GitLab и загрузите содержимое этой папки. Не загружайте ZIP как единственный файл: проверяющим нужны исходники.
3. Если используете Git из терминала, выполните из корня проекта:

```bash
git init
git add .
git commit -m "feat: complete driver shift diary"
git branch -M main
git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
git push -u origin main
```

4. Убедитесь, что README отображается, репозиторий публичный, GitHub Actions выполняются.
5. В анкету отправьте URL репозитория. Демо/скриншоты необязательны.

Описывая использование ИИ, укажите совместный workflow честно: Claude — план/инфраструктура/тесты, Codex — продолжение реализации и проверки. Вы согласовали требования и отклонили лишнее правило 24 часов. Не утверждайте, что вручную написали исправления, реализованные с помощью ИИ. Реальные ошибки перечислены в AI_USAGE.md.
